 WheatGuard – AI-Powered Wheat Disease Detection

WheatGuard is an AI-powered mobile application developed as a Final Year Project to identify wheat diseases from leaf images using deep learning.

Features
- Wheat disease classification using TensorFlow Lite
- Flutter-based mobile application
- Firebase authentication and cloud database
- AI-powered agricultural chatbot using Google Gemini
- Weather updates, agricultural news, and market prices
- Multilingual support: English, Urdu, and Punjabi

Tech Stack
- ML:Python, TensorFlow, TensorFlow Lite
- Mobile:Flutter, Dart
- Backend: Firebase, Cloud Firestore, Firebase Storage
- APIs:Google Gemini, OpenWeatherMap, NewsAPI

Worked on dataset preparation, image preprocessing, model training experiments, and evaluation for wheat disease classification.
